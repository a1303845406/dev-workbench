# 详细设计（候选稿，修订版）

## 1. 范围与特性映射
覆盖 F-BOOK-CRUD（书目登记与查询）、F-BOOK-ARCHIVE（归档）、F-LOAN-OUT（借出）、F-LOAN-RETURN（归还）。技术沿用本机 FastAPI + SQLite + Vue 单页，仅一个可信管理员，不做登录。不进入编码，不写执行脚本。

## 2. 通用约定
- 日期格式 YYYY-MM-DD，本地日历日；借出日、归还日均不得为未来日期；归还日不得早于对应借出日。
- 代号仅限 A01–A10，借出时手填。
- 字符串统一 trim 后校验：code 1–64 字符、title 1–200 字符、isbn 可空且不超 32 字符；isbn 非必填，不校验 ISBN 校验位。
- created_at 由服务端生成，UTC ISO8601（如 2026-10-28T06:30:00Z），不接受客户端传入。
- 422：格式/必填/取值校验失败，保留输入，不写入。
- 409：业务冲突（编码重复、已有未归还记录、重复归还、归档有未归还记录、已归档再归档），保留输入，不重复写入，历史不变。
- 503：数据库繁忙（有限等待后仍锁），可重试，不误判为 409。
- 防重复提交：前端提交后禁用按钮并显示“提交中”；服务端以 BEGIN IMMEDIATE 单事务 + 数据库唯一约束兜底，双击只写一笔。

## 3. 接口

### F-BOOK-CRUD
- POST /api/books：请求 {code, title, isbn?}。成功 201 返回 {id, code, title, isbn, archived:false, created_at}。code 重复 409；code/title trim 后为空或超长、isbn 超 32 返回 422。
- GET /api/books?archived=false|true|all：默认 archived=false（仅未归档）。返回 {items:[{id, code, title, isbn, archived, active_loan:bool, created_at}]}。

### F-BOOK-ARCHIVE
- POST /api/books/{id}/archive：无请求体。成功 200 返回 {id, archived:true}。存在未归还记录 409；书目不存在 404；已归档再归档 409（不可逆）。

### F-LOAN-OUT
- POST /api/loans：请求 {book_id, member_code, loaned_on}。成功 201 返回 {id, book_id, member_code, loaned_on, returned_on:null}。member_code 非 A01–A10、日期格式错或为未来日期 422；书目不存在 404；书目已归档或已有未归还记录 409。

### F-LOAN-RETURN
- POST /api/loans/{id}/return：请求 {returned_on}。成功 200 返回 {id, book_id, member_code, loaned_on, returned_on}。日期格式错、未来日期或早于借出日 422；借阅记录不存在 404；无未归还记录或重复归还 409，历史不变。
- GET /api/loans?book_id=&status=active|returned|all：返回 {items:[{id, book_id, book_code, book_title, member_code, loaned_on, returned_on, status}]}，status 取 active|returned；book_id 不存在时返回 404 {error:"book_not_found"}。

## 4. 事务与校验顺序
- 每连接执行 PRAGMA foreign_keys=ON。
- 借出、归还、归档三种写操作均 BEGIN IMMEDIATE：先做格式校验（422），再在事务内查业务状态并写入，唯一约束冲突整体回滚返回 409。
- 归还使用条件更新：UPDATE loans SET returned_on=? WHERE id=? AND returned_on IS NULL，检查 rowcount；为 0 则回滚返回 409（无未归还记录或重复归还）。
- 数据库繁忙：设置有限 busy 等待，超时后回滚返回 503 并提示可重试，不映射为 409。

## 5. 原型说明
原型为静态 HTML + 内联 CSS，无脚本、无外链、无表单提交与跳转，展示登记、列表/归档筛选（默认未归档）、借出、归还与历史、错误与空状态、防双击状态说明，含表单标签。
