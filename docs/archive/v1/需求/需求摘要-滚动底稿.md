## 三、需求摘要（全量清单版 · 待冻结）

### 产品概述（v1.0）
一个部署在局域网内、团队共享使用的 AI 辅助开发 Web 工作台。内置多角色 Agent 流水线引导完成需求探索与编写，提供规范目录结构的初始化与存量规整能力，核心是**动态模块组合的提示词工程引擎**——按开发流程拆分 10 个可组合模块，依据任务复杂度自动选择组合，按外部 IDE 上下文窗口上限拆分任务粒度，逐模块生成可直接投喂外部 IDE 的提示词与测试用例。工具本身不写代码，产出物是规范文档 + 可执行提示词。

### 第 16 轮（2026-09-28）— 模型间对话编排机制（FR-04 规则 9）

  6. **预算联动**：输入包组装后校验，超限先压上游层为路径引用，仍超则阻断
  7. **全量落盘**：每环输入输出存 pipeline/orchestration/，可复现可审计

### F3 动态模块组合引擎（R8 修订后形态）
```
输入：需求文档/原始诉求（手动选择上下文）+ 项目信息
  ↓
模块选择（agent 自动，用户可干预）：
  模块池 = [需求][概设][原型][详设][数据库设计]
           [后端开发][前端开发][测试][回归][验收]
  依据 = 任务复杂度 + 任务所处层面
  硬约束 = 最小组合 ⊇ {需求, 任意开发类, 测试, 验收}
  ↓
任务拆分（全局规则）：每个模块内按外部 IDE 上下文窗口上限切任务单元
  ↓
逐模块逐任务生成提示词 → 测试模块产出功能/业务用例（性能可选）
  ↓
交付：一键复制 / 导出文件 / 按项目归档成提示词库
```

组合示例（非穷举）：
- 简单 CRUD 小工具：需求→后端开发→测试→验收（4 模块最小组合）
- 中型 Web 系统：需求→概设→数据库设计→后端开发→前端开发→测试→验收
- 复杂平台：10 模块全上（含原型、详设、回归）
