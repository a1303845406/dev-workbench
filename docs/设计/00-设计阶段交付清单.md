## 3 本轮明确不做

- 不创建 FastAPI/Vue 项目，不安装依赖，不启动开发服务器；
- 不实现 Provider、SSE、文件扫描、目录写入、代码索引、备份、鉴权或真实导出；
- 不执行 AOCI-CODE/tree-sitter POC，不确认其 license、性能或兼容性；
- 不把原型中的“模拟创建/扫描/执行/复制”解释为真实产品能力；
- 不提前实现二期局域网 HTTPS、账号权限、代码切片注入、Git 深度集成、回收站或并发冲突处理。

## 4 评审后进入开发前的门禁

1. 用户确认 SRS V1.2.2 与本设计评审稿的范围/优先级；
2. 确认总体技术选型及项目目录/稳定 ID/原子提交方案；
3. 批准批次 0 POC 排期，冻结 AC-03 与预算单位/系数；
4. 明确外发确认、脱敏、Provider Key、路径白名单的安全验收口径；
5. 将用户意见记入滚动底稿，形成设计基线版本；
6. 之后才拆开发任务；本交付物不自动触发开发。
