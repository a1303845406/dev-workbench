## 1 设计原则

1. **中文界面、桌面优先**（SRS 5.1）：最小支持宽度 1280px，不做移动端适配；
2. **状态在文件里，界面是视图**：页面顶部常显"最近落盘时间"，任何确认动作后即时回显落盘结果（呼应 FR-06）；
3. **知情确认前置**（G-10）：一切模型外发动作先弹"外发范围确认"对话框（目标 Provider + 文档清单 + 估算字符量），未确认不发起；
4. **危险操作强确认**（S-01）：删除类操作输入名称确认；脱敏命中项逐条裁决（FR-04 规则 7）；
5. **低视觉噪音**：后台工具风格，信息密度中等偏上，主色低饱和；状态色语义固定（见 §6）。

## 3 全局布局与全局组件

```
┌────────────────────────────────────────────────────────────┐
│ 顶栏：产品名 | 当前项目面包屑 | SSE 连接状态● | 落盘时间 | 系统设置 │
├──────────┬─────────────────────────────────────────────────┤
│ 项目侧栏  │  内容区（各页面）                                 │
│ ①~⑦ 导航 │                                                 │
│ +占用提示 │                                                 │
└──────────┴─────────────────────────────────────────────────┘
```

| 全局组件 | 触发 | 行为 |
|----------|------|------|
| 外发确认对话框 | 任何模型调用前 | 列 Provider 名/模型、包含文档清单、估算字符量；"确认并发起"→记录 confirmed_at（G-10/NFR-12） |
| 脱敏裁决抽屉 | 复制/导出前命中 | 逐条列出 rule_id/摘录（打码）/位置；confirm 级可勾选放行，block 级禁用并阻断 |
| 占用警告横幅 | 409 PROJECT_LOCKED / lock 事件 | 顶部黄色横幅"项目正在其他窗口编辑（窗口 id/时间）"，不阻断（S-04） |
| 挂起恢复条 | plan suspended / 流水线 suspended | 内容区顶部红色条："挂起于 <环/阶段>，前序结果已保存"，按钮"从断点恢复"（AC-06/AC-14④） |
| 流式输出面板 | ring.delta / chat 流式 | 等宽字体增量渲染 + "生成中"指示（NFR-02） |
| 交接摘要过期提示 | handoff.stale | 定稿卡片上黄色角标 + "一键重新生成摘要"按钮（AC-16） |

## 4 页面详设

### 4.1 项目列表页

- 卡片网格：项目名/模板/创建时间/进行中流水线徽标（来自 state/index）/最近落盘时间；
- 操作：新建项目（向导）、打开、删除（输入项目名的强确认对话框，S-01）；
- 空态：引导"创建第一个项目"。

### 4.2 新建项目向导（FR-02）

- 步骤 1 选模板（内置/自定义卡片，含目录树预览）；步骤 2 填项目名（实时校验安全字符集）；步骤 3 确认页（目标路径 + 将生成的骨架树）；
- 同名冲突 → 行内错误"目录已存在"（AC-02）；成功 → 结果页展示生成的目录树（含 rules.md 骨架标注 G-07）→"进入工作台"。

### 4.3 需求探索工作区（FR-01）

- 布局：左列七阶段步骤条（S1~S7，S5 显示"可跳过"角标）；中列对话流（每轮用户/需求师气泡 + 产出卡）；右列**滚动底稿面板**（六区折叠树，实时刷新，可展开查看/手动编辑）；
- 关键交互：
  - 每轮对话前弹外发确认（§3）；流式渲染回复；
  - 阶段产出卡底部固定"确认并推进"按钮 + 意见输入框；未确认时下一阶段置灰（AC-01 可视化）；
  - S4 产出卡内"三角度自审"固定分区展示；S5 两段冻结 = 两个带时间戳的确认按钮；S7 问题清单按 严重/一般/建议 分组，严重项逐条"采纳/驳回/改判"裁决控件，修订版文档问题编号可点击高亮（编号复核可视化）；
- 状态：每阶段 draft/confirmed 徽标 + 最近落盘时间。

### 4.4 项目规整工作区（FR-03）

- 表单：同机路径输入 + 白名单提示 + 深度/条数上限 + 排除规则；"开始扫描"→ 进度条（SSE）；
- 结果页签：结构画像（语言构成饼表/目录健康度列表/依赖摘要）｜规整建议表（级别列：自动归位=绿标签/需人工决策=橙标签；勾选低风险建议 →"确认并生成整改方案"→ 交人工或外部 IDE 执行，不直接修改源文件）；扫描中断 → "从中断处续扫"按钮。

### 4.5 提示词工程工作区（FR-04，六步工作流）

顶部步骤条：`① 勾选上下文 → ② 复杂度与模块组合 → ③ 任务拆分 → ④ 编排计划 → ⑤ 环执行与自动推进 → ⑥ 提示词管理`（V1.2.3：⑤按"落盘即推进"命名，⑥为全环/全阶段管理视图）

| 步骤 | 内容与交互 |
|------|-----------|
| ① | 项目文档树多选（含需求文档/结构画像等），选中项字符量实时合计；继续 → 外发范围预览 |
| ② | 三档复杂度单选（简单/中等/复杂）→"获取组合建议"→ 展示映射表来源与建议组合；硬约束行（需求/开发/测试/验收）锁定标灰并注明"最少四模块硬约束"；用户可增删模块（偏离映射时标注"已人工调整"） |
| ③ | 任务层级树（V1.2.3：parentId/level 多级拆分，容器任务折叠/展开且不直接执行；叶子显示 est/预算，超预算红色 + "拆分"按钮 + "按预算自动拆分（模型 × 上下文窗口）"）；存在超预算叶子时阻断进入编排计划；依赖列标注先后关系，同层无依赖叶子可并行；确认后落 tasks.json |
| ④ | 编排计划表（环 id/任务×模块/顺序/并行组/依赖），支持拖拽调序（非法前移禁用）；"预算预演"列显示四层字符占比条；确认 → 执行（AC-14①②） |
| ⑤ | 环执行监控（V1.2.3 自动推进）：环卡片状态流（排队→生成中[流式面板]→完成[落盘✓→自动推进下一环，定稿不阻断]），失败重试计数，挂起 → 恢复条（§3）；上游摘要过期（HANDOFF_STALE）阻断下游执行；每环可点开 input.md 四层分节查看（审计视图） |
| ⑥ | 提示词列表（全环 / 全阶段管理视图）：预览态 draft → 右侧编辑器（Markdown 编辑+预览双页签）→"定稿"（定稿仅约束归档导出与摘要取材，不阻断推进，V1.2.3）；定稿内容变更触发 handoff.stale 检查提示（AC-16）；"复制"按钮 → 脱敏裁决抽屉 → 放行后写剪贴板（非安全上下文降级提示，NFR-06） |

### 4.6 测试用例视图（FR-05）

- 生成表单：任务多选 + 性能开关（默认关）；用例集按任务分组展示，徽标区分 功能/业务/性能；每条显示覆盖编号（点击跳转需求条目）；回归页签展示回归提示词（生成/复制）。

### 4.7 任务看板（G5）

- 四列：待投喂/已投喂/已完成/失败；卡片=任务单元（模块徽标+标题+关联提示词数）；点击流转状态（失败列必填一行备注 → 写 feedback.md，G6）；列头计数 + 项目进度条。

### 4.8 资产库（FR-07/FR-08）

- 左树：需求产物/提示词（模块→任务→版本）/测试用例/结构画像/导出物；
- 提示词详情：版本时间线；任两版勾选 →"对比"（左右双栏，行级差异高亮）；"回滚到此版"（生成新版本号，不删历史，AC-07）；
- 反馈区：单行备注表格；"导出"按钮 → 格式选择（Spec Kit/Taskmaster/OpenSpec/通用 Markdown）→ 脱敏门 → 下载。

### 4.9 工具注册表页（FR-08，项目设置内页签）

- 表格：名称/类别/启用开关/说明（附录 F 默认清单预置）；增删改即时保存 tools.json；禁用全部工具时顶部提示"协同工具未启用，主流程不受影响"（CON-13 可视化）。

### 4.10 系统设置页（只读，S-02）

- 分区只读展示：Provider（名称/Base URL/模型/Key=***）、模板清单、模块提示词模板版本、复杂度映射、硬约束包（版本号+条目预览）、脱敏规则、备份策略与最近快照、日志目录；配置文件被外部修改后经 `config.reloaded` 事件刷新并显示"已于 xx:xx 热加载"（AC-11）。

### 4.11 项目设置页

- rules.md 编辑器（保存时冲突告警条：命中关键词/行号，警示不阻断，AC-17）；scan_roots 白名单管理；删除项目（强确认）。

## 5 关键交互规范

| 规范 | 约定 |
|------|------|
| 确认门样式 | 一律主按钮蓝色"确认并推进"，副按钮"退回修改"；不可推进时按钮置灰并悬浮说明原因 |
| 流式渲染 | 打字机式增量 + 顶部"生成中…"呼吸点；完成后自动落盘提示 toast |
| 错误态 | 4xx 业务错误行内展示（含 error.code 便于对照接口文档）；50x 顶部红色横幅 + 重试 |
| 空态/加载态 | 每列表页定义骨架屏；空态给下一步引导按钮 |
| 复制降级 | Clipboard 不可用（非安全上下文）→ 弹层展示全文 + "手动全选复制"提示（NFR-06/AC-10） |

## 6 视觉基调

- 主色 `#2F54EB`（低饱和蓝）；状态色：成功 `#52C41A` / 警示 `#FAAD14` / 危险 `#F5222D` / 挂起 `#FA8C16`；
- 字体：系统栈（中文优先微软雅黑/苹方），正文 14px，代码/提示词等宽 13px；
- 布局密度：默认紧凑；支持亮色（一期唯一主题）。
